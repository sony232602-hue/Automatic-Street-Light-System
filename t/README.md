# Automatic Street Light System

## Overview

The Automatic Street Light System automatically turns street lights ON during low-light conditions and OFF during daylight. The system uses a Light Dependent Resistor (LDR) sensor to detect ambient light intensity and control the street light accordingly.

## Objectives

* Reduce electricity consumption.
* Automate street lighting.
* Improve energy efficiency.

## Components Required

* Raspberry Pi / Arduino
* LDR Sensor
* LED
* Resistor
* Breadboard
* Jumper Wires

## Working Principle

1. LDR measures ambient light intensity.
2. If the light level is below a predefined threshold, the street light turns ON.
3. If the light level is above the threshold, the street light turns OFF.
